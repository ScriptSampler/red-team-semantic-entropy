## Why this file exists, and the rule it obeys

The last scheduling argument in this project rested on `~60 GPU-h`, which was a **model**
(55 clusterings/target x ~55 s, where the 55 s came from a K=8 probe used to cost a K=50 run)
and never a measurement. Re-derived from the run's own wall clock it was 23-26 GPU-h.
`results/operational_number_audit.md` then found that **all four load-bearing cost anchors in
the repo were dead**, and that one of them was printed in `paper/sections/experiments.tex`.

So every number below carries a tag:

- **MEASURED** — an artifact and the measurement are named.
- **DERIVED** — arithmetic from measured inputs, shown inline.
- **ASSUMED** — the assumption is named, and the number is not treated as evidence.

An untagged number is the failure mode. Where nothing can be measured yet, the row says
**not measurable yet** and says what would make it measurable. No plausible figure is
substituted for a missing one.
