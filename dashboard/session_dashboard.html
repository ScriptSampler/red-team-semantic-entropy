A web page cannot write to disk, so this downloads a file called STOP.txt. A watcher inside WSL polls for it every 15 s, kills every GPU process, and releases the machine. Nothing is lost — every job checkpoints per target, so a stop costs at most one target.

If the button does not work
  1. Save any file named STOP.txt into Downloads, or
  2. in the repo root, right-click → New → Text Document and name it STOP — file extensions are hidden on this PC, so typing STOP.txt there really makes STOP.txt.txt. Both are watched, so either works.
  3. run wsl -d Ubuntu-24.04 -- pkill -f venv-wsl — the -d Ubuntu-24.04 is required; the default distro is a different, stopped one, and omitting it would silently match nothing.
All of these are watched. The watcher renames the file once it acts, so a later relaunch is not immediately killed by a stale signal.
